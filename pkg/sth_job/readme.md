**统一任务调度组件（sthjob 任务队列框架）**

**项目简介**：自研轻量级通用任务调度框架，支持「Redis 消息队列消费」与「数据库表任务 + 分布式锁」双模式，统一封装任务消费、状态管理、监控采集与优雅关闭的全生命周期。

**职责与亮点**：

**1. RmqJob —— 高实时消息队列消费组件**

* 基于 adjust/rmq 库二次封装，实现队列创建、多 Worker 注册、限速消费的开箱即用能力，大幅降低业务接入成本
* 设计未 ACK 任务定时自动清理机制，有效防止任务卡死与丢失，保障任务执行的可靠性
* 内置队列指标（metrics）采集与周期性日志输出，为运行监控与容量评估提供数据支撑
* 支持优雅关闭，进程退出时可平滑停止消费，避免任务中断

**2. DbJob —— 可持久化的数据库任务调度组件**

* 以「数据库表即队列 + Redis 分布式锁」实现多实例分布式消费，仅依赖 MySQL + Redis，无需引入额外 MQ 中间件，部署运维成本低
* 任务即表记录，状态流转（初始 → 执行中 → 完成）全程落库、可审计、可手工干预与重跑，天然具备持久化能力
* 抽象 ITask 接口，业务任务实现少量方法即可快速接入，扩展性强
* 通过批量拉取任务与成功状态批量回写（每秒聚合、分批落库），显著降低数据库写压力
* 采用短锁设计（仅在取任务、置状态期间持锁），缩短锁持有时长，支撑多实例并行消费
* 引入超时重置兜底机制自动恢复卡死任务，配合优雅关闭时的任务回滚/回写，最大限度避免任务丢失

**项目价值**：一套框架同时覆盖「高实时消费」与「持久化可审计」两类典型场景，核心链路用消息队列、兜底补偿/离线加工用数据库任务，可按业务灵活选型，兼顾实时性与可靠性。
