# 设计文档模板

> 用途：每次改动立项时，复制本文「模板正文」到 `docs/需求名称-design.md`（主干中文命名），并按 AGENTS.md「文档与进度管理」执行编号与流转。本模板仅约束设计文档结构；`curr.md`、`plan.md` 的格式规则见 AGENTS.md，无模板、不重建。

## 各段写什么

| 章节 | 内容要求 |
| --- | --- |
| 首行注释 | `<!-- Dnn \| 状态：草稿/进行中/已完成 -->`，Dnn 全局递增、永不复用 |
| 问题 | 现状痛点或需求来源，动机写清楚，引用来源文档（相对路径链接） |
| 规则与约束 | 本改动必须遵守的工程与流程规则，一律链接引用，不复述正文 |
| 方案与决策记录 | 方案设计与关键决策；开发期间新决策只写在这里 |
| 状态勾点 | 关键里程碑 checklist，随开发实时勾选 |
| 验收结论 | 验收完成后填写：日期、结论、遗留事项；随后执行收尾归档 |

## 模板正文

```markdown
<!-- Dnn | 状态：草稿 -->
# 需求名称

## 问题

## 规则与约束

## 方案与决策记录

## 状态勾点（关键里程碑）

- [ ] …

## 验收结论

（待验收完成后填写）
```

## 收尾归档提醒

验收完成后按 AGENTS.md 收尾顺序执行：勾点全部勾满并填写验收结论 → `plan.md` 勾除条目注明结论 → `curr.md` 更新摘要 → 本文档移至 `docs/history/` 并按新位置修正相对链接。
