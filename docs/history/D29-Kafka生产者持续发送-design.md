# Kafka生产者持续发送

## 问题
手动消费验证需要生产者持续发送，现有 CLI 仅支持有限条数。

## 规则与约束
遵循 [工程规范](../../项目规范.md)、[工作流](../../AGENTS.md)，仅修改测试工具，不扩展生产 Kafka 组件。

## 方案与决策记录
- 新增 -continuous（默认 false）、-interval（默认 1s、必须为正，持续模式生效）。
- 持续模式不允许同时显式指定 -count；首条立即发送，之后每次成功发送后等待 interval，始终串行。
- 有限模式保持 count 和全部发送总期限；持续模式 timeout 是每条发送期限，不限制总运行时间。
- Ctrl+C/SIGTERM 取消后停止发送并关闭客户端，CLI 正常退出；真实发送、输出失败仍非零退出。
- 不追加额外业务重试；取消时未确认消息可能已到达 Broker，不提供事务回滚。
- 参数、有限发送、持续发送超过单条期限仍继续、间隔取消和错误传播通过单元测试；真实集成测试继续使用独立主题和组。
