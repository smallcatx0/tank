# HTTP 请求标识透传

## 问题

用户要求从 HTTP request_id 请求头读取标识，写入 Gin 上下文，实现基础链路关联。

## 规则与约束

遵循 [仓库协议](../../AGENTS.md) 与 [项目规范](../../项目规范.md)。

## 方案与决策记录

增加 Trace 中间件，读取 request_id 请求头，写入现有 RequestIDKey 上下文键。未传时保持空字符串，不生成新 ID。中间件在 Recovery 前执行；统一响应沿用现有读取方式，系统错误及 panic 日志补充 request_id 字段。httpmd 的上下文键引用 resp 常量，避免重复维护。仅提供 HTTP 标识透传，不增加 RPC 或下游传播。
