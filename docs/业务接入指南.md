# 业务接入指南

## HTTP 接口

1. **定义参数。** 在 [models/valid](../models/valid/shop.go) 中定义请求结构，填写 `json` / `form` 和 `binding` 标签；复合校验实现 `Valid() error`。单个接口的简单参数也可使用局部结构体。

2. **实现控制器。** 在 `controller/v1/` 新增业务文件，参考 [shop.go](../controller/v1/shop.go)，依次完成：
   - 用 `valid.BindJsonAndCheck` 或 `valid.BindQueryAndCheck` 绑定参数。
   - 调用业务逻辑，传递 `c.Request.Context()`，为外部调用设置超时。
   - 失败调用 `resp.Fail(c, err)` 后返回；成功调用 `resp.Succ(c, data)`。
   - 分页使用 `resp.NewPage(c)`、`pg.Calc(total)`，通过 `resp.Paginate(c, pg, list)` 返回；数据库查询可使用 `pg.Paginate(q)`。

3. **注册路由。** 在 [routes/router.go](../routes/router.go) 的 `registAdmin` 中添加路由，并导入 `v1 "serv_tpl/controller/v1"`：

   ```go
   group := r.Group("/admin/shop")
   shop := &v1.Shop{}
   group.POST("/create", shop.Create)
   group.GET("/list", shop.List)
   ```

   需要认证时，在路由组挂载认证中间件。新增路由分组在 [routes/router.go](../routes/router.go) 的 `RegisterHTTP` 中调用；启动装配通过 `routes.RegisterHTTP` 加载 HTTP 路由。

4. **补充测试。** 参考 [路由测试](../routes/router_test.go)，使用 `httptest` 验证路由、参数校验、业务结果及错误响应；涉及数据库时补充数据访问测试。

## gRPC 接口

1. **定义协议。** 在 `api/业务名/v1/` 新建 `.proto`，定义请求、响应和 service，参考 [version.proto](../api/version/v1/version.proto)。

2. **生成代码。** 按 [协议生成步骤](gRPC版本查询.md#修改协议后重新生成) 将命令中的 proto 路径替换为新文件，生成并提交 `.pb.go` 和 `_grpc.pb.go`。

3. **实现控制器。** 在 `controller/rpc/` 新增服务实现，参考 [version.go](../controller/rpc/version.go)：
   - 嵌入生成的 `UnimplementedXxxServer`，实现 RPC 方法。
   - 校验请求字段，传递 `context.Context` 调用业务，并设置外部调用超时。
   - 成功返回 `reply, nil`；失败返回对应的 `status.Error(codes.Xxx, "错误提示")`。
   - 取消或超时使用 `status.FromContextError(err).Err()` 转换。

4. **注册服务。** 在 [routes/grpc.go](../routes/grpc.go) 的 `RegisterGRPC` 中添加生成的注册调用及对应导入。以 Version 服务为例：

   ```go
   versionv1.RegisterVersionServiceServer(server, &rpc.VersionService{})
   ```

   新服务替换为对应的包、注册函数和实现类型；所需依赖在此构造并传入。

5. **补充测试。** 参考 [gRPC 测试](../internal/bootstrap/grpc_test.go)，使用生成客户端验证 RPC 往返、参数校验、错误码及取消超时。

## 启动与验证

1. 按 [配置模板](../conf/app.yaml.example) 准备 `conf/app.yaml`，配置数据库和监听端口；使用 gRPC 时设置 `grpc.enable: true`。涉及新表时准备对应 SQL。

2. 在仓库根目录启动 API：

   ```powershell
   go run ./cmd/api -config conf/app.yaml
   ```

3. HTTP 按注册的方法和路径发送请求，可携带 `request_id` 请求头关联响应与日志，处理器通过 `c.GetString(resp.RequestIDKey)` 读取；RPC 使用生成的 `NewXxxClient` 调用并设置 deadline，客户端写法参考 [grpc_version](../test/grpc_version/main.go)。

4. 运行相关检查，并按新增业务补充测试包：

   ```powershell
   go test ./models/valid ./controller/... ./routes ./internal/resp
   go test ./internal/bootstrap -run '^TestGRPC' -count=1
   go vet ./controller/... ./routes ./models/valid
   go build ./cmd/...
   ```

5. 按 [项目规范](../项目规范.md) 完成测试要求，按 [仓库流程](../AGENTS.md) 同步 SQL、接口说明及设计文档。
